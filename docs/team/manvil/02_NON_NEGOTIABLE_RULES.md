# Manvil — Non-Negotiable Rules

1. Evidence provenance is immutable. Never upgrade an existing weak record in place.
2. Artifact-backed evidence is a new derived record with explicit lineage.
3. Verification state is separate from evidence type and never means universal truth/mastery.
4. Every verification is scoped to a claim, context, verifier authority and time.
5. Human/issuer verification and correction history is append-only and auditable.
6. Never auto-verify with AI, file presence, OCR output or a clean scan.
7. A `clean` scan only means the current artifact-safety policy permits use; it does not validate content. `not_scanned` must be truthful.
8. Private artifacts remain private and use authorized storage paths/access.
9. Fail closed for missing consent, wrong organization/role, expired request or inaccessible artifact.
10. Never grant broad service-role access or write trusted tables directly.
11. Do not invent DigiLocker/NAD, issuer, scanner or credential connections.
12. Faculty-as-verifier is a scoped role; do not absorb Nipun's broader faculty lifecycle.
13. Do not change frozen migrations, trust policies, Engine B or other owners' components without approval.

Stop if you need new verifier authority, provenance semantics or schema. These are architectural decisions, not UI conveniences.
