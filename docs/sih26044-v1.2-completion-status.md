## Deployment Procedure (When Credentials Available)

### Step 1: Supabase Setup

```bash
# Set environment variables
export SUPABASE_URL=https://YOUR_PROJECT.supabase.co
export SUPABASE_ANON_KEY=your_anon_key
export SUPABASE_SERVICE_ROLE_KEY=your_service_role_key

# Apply migrations
cd supabase/migrations
# Run migrations in order via Supabase SQL editor or CLI

# Create test actors and organizations
# Run fixture SQL (when created)
```

### Step 2: Worker Deployment

```bash
cd worker
npm ci

# Set secrets
npx wrangler secret put GROQ_API_KEYS
npx wrangler secret put SUPABASE_URL
npx wrangler secret put SUPABASE_ANON_KEY
npx wrangler secret put SUPABASE_ELEVATED_KEY

# Deploy
npm run deploy
```

### Step 3: Client Deployment

```bash
cd ..
npm ci

# Update .env.production
echo "VITE_SUPABASE_URL=$SUPABASE_URL" > .env.production
echo "VITE_SUPABASE_ANON_KEY=$SUPABASE_ANON_KEY" >> .env.production
echo "VITE_WORKER_URL=https://your-worker.workers.dev" >> .env.production

# Build and deploy
npm run build
# Deploy dist/ to Cloudflare Pages or other hosting
```
